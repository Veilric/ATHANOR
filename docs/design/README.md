# Athanor interface reference

Open [the standalone Tide preview](athanor-tide-preview.html) in a browser. It works without a development server or external assets. The approved initial state is the pinned, empty input bar at 65% opacity.

Select a sample task to see the expanded panel, or select Try pinned idle to clear the query and observe its three-second collapse. Typing expands results immediately; the small pin control remains available in the compact state.

This is an approved visual study with simulated files, app results, and currency data. It does not implement the native Rust/Rune application. The supported preview expressions are deliberately limited.

The complete product decisions are in [the design document](../superpowers/specs/2026-11-11-athanor-design.md).
